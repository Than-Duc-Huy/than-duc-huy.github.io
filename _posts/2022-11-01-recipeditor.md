## Project Description

The project was done in a team of 4 for a Software Engineering (Object-Oriented Programming) module in NUS. We created a hybrid CLI-GUI application that allows the user to write down and store their cooking recipe.

Since my background was from EEE, doing hardware, learning robotics algorithm, having spontaneous DIY/Maker inspiration without proper documentation, this module made me to appreciate the structure and workflow of a well-maintained software application.
